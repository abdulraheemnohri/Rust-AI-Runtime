# Rust AI Plugins

Modular plugins for the Rust AI Ecosystem.

## Available Plugins
- `voice_assistant/`: Processes voice commands and provides AI-driven responses.
- `summarizer/`: Generates concise summaries from long-form text.
- `analytics/`: Provides AI-powered data analytics and insights.

## Development
Each plugin is a Rust library that can be compiled to a dynamic library (`.so`, `.dll`, or `.dylib`) and loaded by the core runtime.
